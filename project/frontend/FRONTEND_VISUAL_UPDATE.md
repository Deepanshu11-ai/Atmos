# Atmos frontend visual update

This update is for `atmos/project/frontend` in the `atmos 2(1).zip` project only.

## Install/run
1. Back up your existing `frontend` folder.
2. Replace it with this updated folder.
3. In the frontend folder, run `npm install`.
4. From the project backend folder, run the API as before.
5. From frontend, run `npm run dev`.

## Visual changes
- New animated globe visual with layered land shapes, grid, orbital rings and CO2 bubbles.
- Floating emissions metric cards.
- Softer white/light-green/forest-green palette.
- Intersection-based, modest reveal motion for the workflow and following sections.
- Responsive layout and reduced-motion support.

No backend, database, API, or environment settings are changed.
